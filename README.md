# Book Buddy

Personal reading companion and book library management application built with Spring Boot.

## Features
- Catalog personal books with authors, ISBNs, categories, and reading status.
- Track reading progress and personal ratings.
- RESTful endpoints for book CRUD and filter queries.

## Tech Stack
- Java 21 LTS
- Spring Boot, Spring Data JPA, Spring Web
- H2 / MySQL Database support
- Maven Wrapper

## Getting Started
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
